How much disk space does an app clone use?

Copying a big app like Slack or VS Code normally doubles its size, often hundreds of megabytes.

Mitosis clones are much smaller.

Quick answer

Usually a couple of megabytes. Mitosis makes an APFS clone, which shares the original app's files on disk; only the few files it changes (the name, badge icon, and launcher) take new space. The clone's data, like logins and caches, grows as you use it.

When a clone uses more

The original is on another drive. APFS can only share files on the same drive, so a clone of an app on an external disk is a full copy. Mitosis tells you the size before it copies.

Data grows with use. Messages, caches, and downloaded updates live in the clone's data folder. Clean Caches on the clone's page frees space without signing you out.

Seeing the numbers

Each clone's page shows Extra disk (what the clone adds), Data, and, while it runs, memory and CPU. In Terminal, mitosis stats "Slack (Work)" shows the same.

Questions

Does Finder show the real size?

Finder shows the full size of the app, because it can't tell which files are shared. The clone's page in Mitosis shows what it really adds.

Does a clone use more memory?

A running clone uses about as much memory as the app normally does; a clone that isn't open uses none.
