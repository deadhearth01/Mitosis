# Mitosis Mac App: Owner Feedback Round (auto-update, icon, redesign)

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Address the owner's feedback on the first app build:
1. Clones update automatically when their original app updates.
2. The Dock icon renders full size on macOS 26+.
3. Managing a clone and seeing its stats is obvious; the UI feels premium.

**Architecture:**
- **Auto-update:** pulls forward the spec's 0.2 "automatic repair" in a light form:
  - The engine gains `refreshOutdated` (atomic rebuild, no launch). It skips running clones and originals that are mid-update.
  - The app runs it whenever statuses change and when a clone quits.
  - A per-user LaunchAgent runs `mitosis refresh --outdated --quiet` when an original app's folder changes (launchd `WatchPaths`, no idle CPU) and every 6 hours as a fallback.
- **Icon:** an Icon Composer `.icon` (white fill + the approved art) compiled by `actool` into `Assets.car` + `AppIcon.icns`.
- **Redesign:** replaces grid + hidden inspector with a sidebar list of clones (grouped by original app, with status), and a full detail page per clone. The detail page has a header with actions, large stat tiles, details and maintenance.

**Spec:** `docs/specs/2026-10-09-mitosis-design.md` §5.7, §6, §14. Owner feedback (2026-10-09) overrides §6's grid layout and §5.7's "0.1 manual".

## Global Constraints
Same as `docs/plans/2026-10-09-mac-app.md`, plus:
- **Automatic updates** never open, quit or interrupt a clone. Running clones wait until they quit. Data and logins are always kept. A failed rebuild leaves the previous clone in place (atomic install).
- **The LaunchAgent** (`com.mitosis-mac.autorefresh`) exists only while "Update clones automatically" is on and at least one clone exists. Turning the setting off removes it.

## Review Focus
- **The original is mid-update** (half-written bundle) when the watcher fires. Expect: skipped this round ("still updating"), retried later; never a broken clone (Task 13).
- **The clone is running when its original updates.** Expect: skipped; refreshed after the clone quits (Tasks 13, 15).
- **The app moved** (for example from Downloads to /Applications). Expect: the agent is rewritten on the next launch to point at the new CLI path (Task 14).
- **Many clones of one app.** Expect: watch paths deduped (Task 14).
- **Auto-update is off.** Expect: the agent is removed, and the app never refreshes on its own (Tasks 14, 15).

### Task 13: Engine and CLI: refresh outdated clones without launching them
**Files:** `CloneMaintenance.swift`, `Sources/mitosis/MitosisCLI.swift`. Tests: `CloneMaintenanceTests.swift`, `CLITests.swift`.

**Interfaces:**
- `public struct AutoRefreshReport: Sendable { refreshed: [String]; skippedRunning: [String]; skippedUpdating: [String]; failed: [String: String] }`
- `CloneMaintenance.refreshOutdated(_ entries: [RegistryEntry]) -> AutoRefreshReport`. For each entry with status `.updateAvailable`:
  - if running → `skippedRunning`;
  - else if `Signer.verify(source)` fails (original mid-update) → `skippedUpdating`;
  - else `refresh` → `refreshed`, or `failed[name] = message`.
- CLI `mitosis refresh --outdated [--quiet]` runs `refreshOutdated` over all clones and prints one line per result (nothing with `--quiet` unless something failed). The exit code is 0 unless something failed.

**Steps:**
- [ ] **Failing tests:**
  - Bumping the source version makes `refreshOutdated` refresh exactly that clone, after which its status is `.upToDate`.
  - With `isRunning` true → `skippedRunning`.
  - Modifying a file inside the source without re-signing → `skippedUpdating`, and the clone is untouched.
  - CLI `refresh --outdated` after a source bump prints `Refreshed "Fixture (Work)"`.
- [ ] Implement until the tests pass, then commit.

### Task 14: AutoRefreshAgent (LaunchAgent plist + install/remove)
**Files:** `Sources/MitosisCore/AutoRefreshAgent.swift`. Test: `AutoRefreshAgentTests.swift`.

**Interfaces:**
- `AutoRefreshAgent.label = "com.mitosis-mac.autorefresh"`.
- `static func watchPaths(for entries: [RegistryEntry]) -> [String]`: each source app's parent folder plus the app's `Contents/Info.plist`, deduped and sorted.
- `static func plist(cli: URL, watchPaths: [String]) -> Data`: `ProgramArguments [cli, "refresh", "--outdated", "--quiet"]`, `WatchPaths`, `StartInterval 21600`, `ThrottleInterval 30`, `RunAtLoad false`, `ProcessType Background`, `LowPriorityIO true`, `StandardErrorPath ~/Library/Logs/Mitosis/autorefresh.log`.
- `sync(cli:entries:enabled:agentsDir:load:) throws -> Bool`:
  - with `enabled` and clones present: writes the plist, but only if it changed, then (re)loads it via `launchctl bootout` + `bootstrap gui/<uid>`;
  - otherwise removes and unloads it.
  - Returns whether anything changed.
  - `load: false` in tests skips launchctl.

**Steps:**
- [ ] **Failing tests:**
  - Two clones of the same app give 2 watch paths (folder + Info.plist), not 4.
  - The plist round-trips with the expected keys.
  - `sync` writes once (second call → false) and removes the plist when disabled or when there are no clones.
- [ ] Implement until the tests pass, then commit.
