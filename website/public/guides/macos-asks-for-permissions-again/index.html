Why macOS asks a clone for permissions again

The first time a clone wants to send notifications, open your Documents folder, or use the camera, macOS asks, even if you already allowed the original app.

Quick answer

That's expected: each clone has its own app identity, so macOS keeps its permissions separate from the original's. Allow what the clone needs, and review it anytime in System Settings › Privacy & Security.

Why it's a good thing

Separate permissions mean you can let your work copy use the camera for meetings while your personal copy can't, or silence notifications from one copy only.

Good to know

  • Notifications for each copy are set in System Settings › Notifications, where each copy appears under its own name.

Questions

Do I have to allow everything again after an update?

No. Updates keep the clone's identity, so its permissions stay.
