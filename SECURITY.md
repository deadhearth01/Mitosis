# Security Policy

## Supported versions

Security fixes go into the latest release of Mitosis.

## Reporting a vulnerability

Please **don't open a public issue** for security problems. Instead, use GitHub's private reporting: open the repository's **Security** tab and choose **Report a vulnerability**.

Include what you found, how to reproduce it, and what an attacker could do with it. You'll get a reply within a week, and we'll credit you in the release notes unless you prefer not to be named.

## Scope notes

Mitosis copies apps, edits the copy's settings, and signs the copy with an ad-hoc signature on your Mac. It never modifies the original app, never needs administrator rights, and has no network features in its clone engine. Reports about any of these guarantees being broken are especially welcome.
