How to test an app with two accounts at once on a Mac

Testing anything with two users, like chat, sharing, or permissions, usually means a second machine, a VM, or constant signing out.

A second copy of the app on the same Mac is faster: user A in one window, user B in the other.

Quick answer

Clone the app with Mitosis (for example Slack (User B)) and sign in as the second user. Both copies run at once, each with its own data folder.

Testing your own Electron app

If your app is built with Electron, Mitosis starts each copy with its own --user-data-dir, so storage, cookies, and logins stay apart.

If your app keeps state outside its user-data folder (like Codex's ~/.codex), the copies will share it. Reading such a folder from an environment variable lets each copy point somewhere else.

Step by step

  1. Install Mitosis

    Paste this in Terminal:curl -fsSL https://raw.githubusercontent.com/deadhearth01/Mitosis/main/scripts/install.sh | bashOr use Homebrew: brew install --cask deadhearth01/tap/mitosis. Free; macOS 15 or later on Apple silicon.

  2. Make a copy

    Click New Clone, choose the app, and add a label like User B.

  3. Sign in as user B

    Open the copy and sign in with the second test account.

  4. Script it

    Prefer Terminal? mitosis clone MyApp --label "User B" does the same, and mitosis delete "MyApp (User B)" --delete-data cleans up.

Good to know

  • mitosis doctor MyApp shows how an app will be cloned before you start.
  • Copies are signed locally; your build's own signature stays as it is.

Questions

Can I automate this in CI?

The mitosis command works in scripts on a Mac, but clones need a logged-in macOS session, so CI runners are hit and miss.

Does it modify my app?

No. Mitosis copies the app and changes only the copy.
